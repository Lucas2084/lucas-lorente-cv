# Foto de perfil

Añade tu foto con el nombre `profile.jpg` a esta carpeta. Se recomienda una imagen vertical de al menos 520 × 580 píxeles. El recorte se adapta al espacio reservado sin cambiar la maquetación.

En `index.html`, actualiza el `aria-label` del elemento `.profile-avatar` a `Foto de Lucas Lorente Arjona` cuando añadas la foto. Puedes ajustar el encuadre con `background-position` en `.profile-avatar::after`, dentro de `style.css`.
